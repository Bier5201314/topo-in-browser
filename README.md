# eNSP 拓扑查看器

一个可以在浏览器中查看华为 eNSP (Enterprise Network Simulation Platform) 拓扑文件的网页工具。

## 功能特性

- 📂 **支持 .topo 文件** - 直接打开 eNSP 拓扑文件
- 🖱️ **拖拽打开** - 支持拖拽文件到页面打开
- 🔍 **缩放和平移** - 支持鼠标滚轮缩放、拖拽平移
- 📱 **响应式设计** - 适配不同屏幕尺寸
- 🎨 **设备分类显示** - 不同类型设备使用不同颜色和图标
- 📋 **设备列表** - 左侧显示所有设备，点击快速定位
- ℹ️ **属性面板** - 右侧显示选中设备的详细信息
- 🔗 **链路可视化** - 显示设备间的连接关系和链路类型
- 📝 **文本注释** - 支持显示拓扑中的文本提示
- ⌨️ **快捷键** - 支持键盘快捷操作

## 使用方法

### 方式一：直接打开（推荐）
直接双击 `index.html` 文件，用浏览器打开即可使用。

### 方式二：本地服务器
如果遇到跨域问题，可以使用本地 HTTP 服务器：

```bash
# Python 3
python -m http.server 8080

# Node.js
npx serve .
```

然后在浏览器访问 `http://localhost:8080`

## 操作说明

### 打开拓扑文件
- 点击顶部「打开拓扑文件」按钮选择 .topo 文件
- 或者直接将 .topo 文件拖拽到页面中央

### 视图操作
- **缩放**：鼠标滚轮 / 点击 + - 按钮 / 键盘 + - 键
- **平移**：按住鼠标左键拖拽画布
- **适应窗口**：点击「适应窗口」按钮 / 按 0 键
- **重置视图**：点击「重置」按钮

### 设备操作
- **选中设备**：点击设备图标或左侧设备列表
- **定位设备**：点击左侧设备列表项自动居中
- **查看详情**：选中设备后右侧显示详细属性
- **取消选择**：点击空白处 / 按 ESC 键

## 支持的设备类型

| 设备类型 | 图标 | 颜色 | 说明 |
|---------|------|------|------|
| 路由器 (AR/NE/ME/ATN) | 🖥️ | 绿色/橙色 | 各种路由器 |
| 交换机 (S/CE/CX) | 🔀 | 蓝色 | 各种交换机 |
| 防火墙 (FW/USG) | 🛡️ | 红色 | 安全设备 |
| 无线设备 (AP/AC) | 📡 | 紫色 | 无线网络设备 |
| 云 (Cloud) | ☁️ | 灰色 | 云/外部网络 |
| PC | 💻 | 棕色 | 终端设备 |
| 服务器 (Server) | 🖧 | 青色 | 服务器设备 |
| Hub | 🔌 | 灰色 | 集线器 |

## 支持的链路类型（与 eNSP 完全一致）

- **Auto** - 自动
- **Copper** - 以太网（红色实线）
- **Serial** - 串行（蓝色虚线）
- **POS** - 光纤（橙色虚线）
- **E1** - E1（青色虚线）
- **ATM** - ATM（紫色实线）
- **CTL** - 控制线（深灰实线）

## 技术实现

- 纯前端实现，无需后端服务
- 使用 SVG 渲染拓扑图
- 原生 JavaScript 解析 XML 格式的拓扑文件
- 支持所有现代浏览器（Chrome、Firefox、Edge、Safari）

## 注意事项

1. 本工具仅用于**查看**拓扑文件，不支持编辑和保存
2. 大尺寸拓扑文件可能加载较慢
3. 部分特殊设备类型可能显示为默认图标
